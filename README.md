# LiteratureMap
Map the Research, Find Your Focus!

一个纯前端的文献引用关系可视化工具。输入一篇文献的 DOI，即可通过 [CrossRef](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、[OpenAlex](https://docs.openalex.org/) 两个公开 API 自动抓取文献元数据、参考文献与被引文献，构建引用关系网络，并用 D3.js 力导向图进行可视化展示。

> 本项目为纯静态 Web 应用，无后端、无构建步骤、无运行时依赖（npm 包），外部库均通过 CDN 引入（D3.js 在首次渲染图时按需加载）。所有数据与上传的 PDF 文件仅保存在本地浏览器。日常开发与运行直接使用 `index.html` + `src/`；如需发布"混淆保护"版本，可运行 `node obfuscate.js` 生成 `dist/`（见「发布混淆版（可选）」，可选行为，不影响"零构建"运行方式）。

## 功能特性

- **DOI 查询与节点新增**：输入标准 DOI（如 `10.1038/nature12373`），自动查询文献元数据并建立节点。
- **多数据源整合**：
  - **CrossRef**（固定主元数据源，元数据最全）：标题、作者、期刊、年份、摘要、参考文献列表。
  - **OpenAlex**（元数据补充 + 被引）：提供完整元数据、被引列表与被引数（`cited_by_count` 权威字段）。被引列表按场景不同口径拉取——**续查被引 / 自动更新 / 数据升级**：`filter=cites:<workId>` 游标分页（每页 100）**全量查尽**（无条数上限，`sort='cited_by_count:desc'` 被引数降序，新查询顺序以此为准）；**自动更新查新**：`sort='publication_date:desc'` 出版日期降序 + `limit=50` + `stopWhenOlderThan=当天` 查新窗口（遇到早于当天的条目即停，当天及更新的被引已全部收入）。全量（未截断）完成后按实时返回条数回写 `cited-by-count-from-openalex`（cites 实时结果为准，works 快照滞后）；查新/限量窗口（截断）不回写。
  - 双源固定并行查询；补充源会**补全主源缺失的字段**（主源优先，不覆盖已有字段）。
- **被引查询链**：续查被引时若尚未拉取过 OpenAlex 被引列表（`_is-referenced-by-queried-openalex` 为 false）则经 `filter=cites:<workId>` 一次全量获取（游标分页查全、不截断），与本地被引结果做**两源并集去重合并**（非整表替换：OpenAlex 条目优先补充 openalexID、手动删除的条目不复活——但隐藏条目的 openalexID 仍随最新列表联动刷新）；`is-referenced-by.data` 存 `{DOI, openalexID}` 对象数组，openalexID 与文献节点自身的 openalexID 字段联动同步，节点缺失时按 DOI 读取元数据；支持仅 W 号（无 DOI）条目按条目级显示 openalex.org 链接（不建节点）。请求失败按指数退避重试（1s / 2s / 4s），404/410 权威"不存在"不重试，429 按 `Retry-After` 等待后重试。同一 DOI 的元数据只请求一次：批量预热缓存 + 并发 in-flight 去重 + 统一任务队列幂等去重保证重复查询不产生额外请求。
- **引用关系网络构建**：递归分析参考文献中的 DOI，建立"引用 / 被引用"关系（有向边），计算每篇文献的被引用次数。
- **参考文献与被引文献列表**：聚焦文献与选中文献卡片的下方均展示 **参考文献列表** 与 **被引文献列表**（结构样式一致），支持"设为选中文献"、"添加DOI"等操作。
- **双继续查询按钮**：聚焦文献卡片提供独立的"继续查询参考文献"与"继续查询被引文献"按钮，批量查询未查询的节点（数量受设置中的最大值限制）。
- **被引次数策略**：以 OpenAlex 权威字段 `cited-by-count-from-openalex`（即 OpenAlex `cited_by_count`）为口径——节点缺失该字段时沿用被引列表展示（不做数组长度兜底，宁缺勿滥）。
- **统一任务队列（按源 × 类型全局待查列表）**：CrossRef / OpenAlex 两源各自持有全局待查队列（OpenAlex 又分元数据 work / 被引全量 cites / 被引数批量回补 cited-count 三种任务类型），**任意时刻**任何查询入口（顶部 DOI 查询、续查引用 / 被引、补查、自动更新、数据升级）都只是把请求登记进队列；源侧"单飞泵"从统一队列取批执行——同 (源, 类型, DOI) 幂等去重（等待者共享同一次查询结果）、已查该源的节点零请求直接跳过（统一过滤，不重复也不漏）。泵内内建：批量预热缓存、单源写回合并、notFound（404/410）防反复重查置已查标记、瞬时失败重试 2 次放回队尾、超限 softFail 交调用方兜底。
- **查询进度双档显示（默认分页）**：信息栏右侧进度条可选「分页」或「合并」两档——分页模式（默认）按源分条各显示一行「源名 N/M + 迷你进度条」（CrossRef / OpenAlex 各一行）；合并模式显示两条线总进度单条。设置面板「分页显示查询进度」开关即时切换，选择持久化。
- **已存在节点自动补差**：顶部输入一个已存在的 DOI 时，若该节点尚未被两个源都查询过，会自动补查缺失的源（不再仅提示"DOI 已存在"）；双源均已查询才走"设为聚焦"快捷路径——配合执行层按源跳过（`isNodeSourceQueried`），任何入口都不会对已查该源的节点重发冗余请求。
- **数据源实时统计**：底部信息条分源显示两个数据源的会话统计（刷新清零）——请求数 / ✓ 成功 / ✗ 失败三者均按**实际 fetch 请求**口径统计（含重试、404/410、超时、断网；缓存命中与批量预热不发起请求不计），唯一计数点收敛在 `fetchJson` 内部；该源队列非空或泵运行中时显示黄色「待查 N」徽章并脉冲高亮。每次请求同时在浏览器控制台打印 `[api] <源> · 发起函数 <fn>() → GET <url>` 日志，便于排查。
- **自动更新被引文献（≥23h 窗口 + 1h 防抖，默认关闭）**：以 `settings.lastUpdatedTime` 记录上次自动更新成功时间、`settings.lastAutoUpdateAttemptAt` 记录上次尝试时间，调度器在页面重载 1 分钟后检查一次、之后每小时检查一次，仅当**距上次成功更新 ≥23h**（不设上限，失败不重置计时、下小时窗口自动重试）且距上次尝试 ≥1h 且开关启用时才执行一轮：对聚焦历史中双源均已查询的文献**直接拉 OpenAlex cites（删除了 works 计数预检对比——快照滞后且与实时存在固有偏差）**，统一查新窗口 `{sort:'publication_date:desc', limit:50, stopWhenOlderThan:当天UTC}`（仅查当天及更新的被引，平均 1 页请求；窗口截断挂 `truncated=true` 不回写被引数），按是否已拉取过 OpenAlex 被引列表分两组——未并入过的（groupA）直接做被引**两源并集合并**（`mergeOpenalexCited`：仅合并写回 + 建空节点，不批量补查、不计入历史、仅计数提示；**全量未截断时按实时条数回写被引数**）；已并入过的（groupB）用 `compareOpenalexCited` 按 **DOI + openalexID 双键**比对"OpenAlex 最新被引列表 vs 本地被引（含手动删除，不复活——隐藏条目 openalexID 随最新列表联动刷新）"寻找新增（仅 W 号按 W 号判新旧，删除过的同一文献不会误判为新增），cites 响应随条携带被引元数据用于建/补节点（不再发额外 OpenAlex works 请求），再以 CrossRef 元数据完善新增节点（不再额外发起 OpenAlex cites 请求），新增文献（含仅 W 号条目）计入自动更新历史（`autoUpdatedHistory`）供「24h 更新」弹层展示；整轮进度在左下角信息栏显示为独立任务（不干扰用户续查）。整轮成功（至少一篇聚焦文献成功拉取）才推进 `lastUpdatedTime`；设置面板提供「立即更新」测试按钮，可无视开关与时间窗口强制执行一轮。
- **24h 更新速览（自动更新历史）**：点击信息栏最右侧「24h 更新」按钮打开弹层，展示 `autoUpdatedHistory`——每次自动更新新增的文献清单（组时间倒序，每组 = 一轮自动更新「新增 N 篇被引文献」+ 时间，默认显示最近 3 组、可点「显示更早的更新」分页加载直至全部；整库保留上限 `max(100, 100×距上次更新天数+100)` 条记录、整组保留不拆）。每组记录下的文献以完整条目展示：左侧计数序号 + 标题、作者、期刊 · 出版社 · 发表日期、DOI 链接与摘要；摘要默认显示 3 行，单击可展开 / 收起（底部渐隐遮罩 + 右下角箭头徽标提示交互）；文献节点缺失或未查询完成时退化为纯 DOI 链接，仅 W 号条目显示 openalex.org 链接。弹层完全本地展示（不发起任何网络请求），无底部按钮，仅右上角 × 关闭。
- **全屏引用关系图 + 悬浮面板**：中央为全屏 D3 力导向图；顶部面板用于新增文献与年份筛选，左右两侧为"聚焦的文献"与"选择的文献"悬浮面板，底部为"Focus 历史记录"面板。所有面板均可折叠或固定。
- **时间范围筛选**：在顶部面板的年份筛选条中通过年份双滑块（起始 / 结束年份）实时过滤图中节点，拖动后节点颜色随时间范围动态重着色。
- **时间排列**：按文献发表年份将节点纵向分列排布；某年节点超过 5 个时自动横向扩展多列，整排布局按列槽总跨度居中。启用后节点间连线默认隐藏，双击某节点可单独显示与它相连的连线（仅作显示、不施加力）。**手机模式下整排自动逆时针转置 90°**：年份改为纵向行排列（早年份在下、晚年份在上），行内节点左晚右早、间隔节点上下微偏移，年份轴竖排于图左端。
- **手机模式适配**：窄屏自动进入手机模式——工具栏全部按钮只显示图标；左右面板互斥开合、固定状态可记忆恢复，聚焦历史面板宽度与左右面板对齐；触摸手势完整支持（双击选中节点、长按弹出操作菜单、探索图内长按拖动生成浮动副本拖入口袋）；时间排列自动切换为上述纵向转置布局。
- **显示模式手动切换**：设置面板可选择「自动 / 电脑 / 手机」三档（默认自动），手动选择即时生效并持久化，可覆盖系统自动判定。
- **设置弹窗一站化**：内含「工作流」操作指引与「操作说明」交互方法；「支持我」栏常驻显示「赞赏码」条目，单击以全屏弹层放大展示二维码（电脑 / 手机模式均可）。
- **深浅色主题（跟随系统）**：全局界面经语义化 CSS 变量自动适配系统浅色 / 深色模式——面板、输入框、d3 节点文字与年份轴、年份滑块轨道、滚动边条、节点圆描边等全部随主题切换。
- **紧凑布局（矮窗口自动收纳）**：电脑模式下窗口高度较矮、底部面板打开会与上面板重合时，自动收起上面板、向下收折底部信息栏（「24h 更新」按钮顺势迁至右工具栏）、工具栏一行沉底；条件消失后自动恢复。
- **面板详情分块与折叠**：左右面板详情分为标题信息 / 摘要 / 参考文献 / 被引文献 / 隐藏的参考文献 / 隐藏的被引文献六块；四个文献列表条目数超过 3 条时默认折叠、仅显示前 3 条，可点击「▾ 展开全部」胶囊按钮展开 / 收起。
- **规则筛选**：支持根据引用关系规则过滤节点与边。
- **卡片组管理**：点击左右边条「第 N / 共 M」指示器进入编辑弹层，点条目右侧 ☰ 手柄拖动即调整卡片顺序（鼠标 / 触屏一致，无需长按），复选框批量删除，双击 / 触屏连点条目跳转到对应卡片组。
- **口袋与共引分析**：底部"Focus 历史记录"面板提供口袋区，可将文献拖入不同口袋，一键生成"多源共同引用关系图"，并可在袋内管理源文献、切换共引筛选模式（严格 ≤2 / 宽松 ≤3）。
- **隐藏聚焦文献连线**：设置项，开启后双向引用关系图中不显示与聚焦文献直接相连的连线（默认开启），便于观察其它引用关系；仅作用于非时间排列状态，时间排列下该设置被忽略，连线由双击选中节点决定。
- **Focus / Selected 视图**：每张卡片可设置"焦点文献"与"选中文献"，高亮展示二者间的引用路径与距离关系（BFS 最短距离）。
- **探索历史图**：记录并可视化整个探索过程的文献访问轨迹（Focus 历史）。
- **文献详情展示**：卡片内展示标题、作者、期刊、出版社、发表日期、DOI、摘要、参考文献及被引文献列表。
- **手动标签**：可为文献手动添加 / 删除标签，标签持久化保存并直接显示在文献详情中。
- **引用复制**：一键复制文献引用信息（支持 HTML 与纯文本两种剪贴板格式）。
- **PDF 补充上传与管理**：聚焦 / 选中文献主条目以及参考文献、被引文献条目均可上传"补充正文 PDF"与"补充 SI PDF"（支持多选）。PDF 按钮显示已上传数量徽标，点击后弹出管理菜单，可查看文件列表、逐个删除或继续添加，文件持久化保存在浏览器 IndexedDB。
- **无效 DOI 处理**：格式非法或数据库中不存在的 DOI 会被置空，并从引用列表与未查询列表移除，不建立空节点。
- **数据持久化**（自动，由统一持久化模块 persistence.js 管理）：
  - 设置（时间排列开关、隐藏聚焦文献连线 等小数据）与 **UI 状态**（页面标题、口袋）保存在 `localStorage`。
  - **文献节点**（v5 平铺 schema，无独立 detail）、**卡片视图**、**探索历史**、**自动更新历史**、**PDF 文件**等结构化数据保存在浏览器 **IndexedDB**，刷新页面自动恢复；引用边与距离图不落盘，加载时由节点关系派生重建。
  - **启动自动数据升级**：每次加载后按数据版本号（`_dataUpgradeVersion`，一次性判定、幂等重跑安全）自动升级旧数据——批量回补旧节点 OpenAlex 权威被引数（`cited-by-count-from-openalex`）、重查被引列表不完整的文献（旧版 200 条截断残留，全量重拉合并）、迁移期补全已 OpenAlex 查询节点的 `_openalex-queried` 标记等；升级成功即刷新图与面板即时呈现新数据，并自动重载一次双保险。
  - 采用"防抖 + 节流 + 页面关闭前强制落盘"的自动保存机制，按域哨兵比对做增量写入，大数据量下也不会丢失最新改动；localStorage 域（设置 / 口袋 / 面板状态）在页面卸载或隐藏时**同步冲刷**，快速连续刷新也不丢最近改动。
  - **导出 / 导入**：仍可将全部数据导出为 JSON 文件下载，或从 JSON 文件恢复完整工作状态。
  - **清空数据**：一键清空浏览器本地保存的全部数据（IndexedDB + localStorage）。
- **交互体验**：力导向图支持缩放（滚轮 / 右下角控制按钮）、拖拽平移、双击定位中心节点、右键删除节点；center 按钮以选中文献节点或图中心为基准；左右边条按钮可在卡片组间切换；点击空白区域自动折叠悬浮面板，固定按钮可防止面板自动折叠。
- **调试辅助**：`trace.js` 提供**关键函数追踪**，按白名单在控制台打印关键函数执行日志（函数名），便于排查调用链。

## 可视化说明

- **节点大小**：表示文献重要度，由「热度-经典性」评分（当前引用速率 × 同龄相对被引的几何加权）决定，并按设置面板的「文献重要性偏好」（热点优先/均衡/经典优先）、「综述抑制强度」（温和/标准/强力，高参考文献数综述自动缩小）、「突出重点」（平衡取对数/突出不取对数）三组偏好实时调整；被引用越多、越近期的文献节点通常越大（被引数缺失/为零按下限 1 计，零被引节点也获得基础热度显示；无年份文献按 50 年前计算年龄，当年文献年龄下限 0.1 年）。
- **节点颜色**：表示文献发表年份（蓝渐变，浅色端自渐变 1/4 处起步避免过浅）。主图按**年份筛选条区间内实际存在的年份**均分布色（同年份同色、稀疏年份拉开色差），聚焦历史图按**该图节点实际年份范围**（最大/最小）映射，年份越新颜色越深。
- **连线方向**：表示引用关系（`A → B` 表示 A 引用了 B）。

```
        ├── data-sources.js  # 多数据源适配（CrossRef 主源 / OpenAlex 补充+被引）、限速、指数退避重试、429 处理、元数据合并、信息栏请求统计
        ├── task-queue.js    # 统一任务队列：按「源 × 类型」全局待查列表 + 单飞泵（幂等入队 / 单源写回 / 错误分级处理 / 信息栏待查数）
        ├── query.js         # 查询逻辑：双源查询、关系更新、批量继续查询、进度状态机（分页/合并双档）、无效 DOI 处理
        ├── graph.js         # D3 力导向图渲染（D3 懒加载）、规则筛选与日期筛选、时间排列、共引筛选
        ├── cards.js         # 卡片组渲染、文献详情、文献列表、PDF 管理菜单、口袋管理、卡片组编辑
        ├── main.js          # 应用入口：面板交互、卡片组切换、导入导出、设置面板、IndexedDB 恢复
        └── trace.js         # 关键函数追踪：按白名单在控制台打印关键函数执行日志
```

## 快速开始

项目无需安装任何依赖，也不需要构建步骤。

> **可选：发布混淆版**：如需对外分发"混淆保护"源码，在项目根执行 `npm.cmd install`（首次，安装混淆工具）后运行 `node obfuscate.js`，将生成的 `dist/` 目录整体部署即可（10 个源码文件合并混淆为单个 `app.js`）；开发源码 `src/` 始终不受影响。可重复运行重新构建。

### 方式一：本地静态服务器（推荐）

Windows 下可直接双击 `start_server.bat` 一键启动；或在项目根目录执行：

```bash
# 任选其一
python -m http.server 7852
npx http-server -p 7852
```

然后浏览器访问 `http://localhost:7852`。

### 方式二：直接打开 `index.html`

可双击直接打开，但浏览器会将 `file://` 视为独立安全源，可能导致 **IndexedDB 数据持久化、剪贴板复制** 等部分功能异常（页面顶部会显示黄色安全提示横幅）。因此**建议优先使用本地服务器方式访问**。

> 提示：`npx` 会临时下载 `http-server`，无需将其加入项目依赖。Tailwind、Font Awesome 随首屏加载，D3.js 在首次渲染图时按需加载，均来自 CDN，需确保网络可访问外网。

## 使用说明

1. **新增文献**：在顶部"新增文献"区域输入标准 DOI，点击"新增节点"或按回车。
   - DOI 格式须符合 `10.xxxx/xxxx` 标准，例如 `10.1038/nature12373`。
   - 每个新节点会自动成为该卡片的"焦点文献"。
   - 下方为 **时间范围筛选条**（起始 / 结束年份双滑块），实时过滤图中节点。
2. **设置**（顶部操作区的"设置"按钮，弹窗内包含「工作流」操作指引、「操作说明」交互方法、查询设置、数据源设置、数据管理、「致谢」（含作者联系方式）与「支持我」（赞赏码）：Crossref / OpenAlex 联系邮箱仅接受**合法且非页面公开**的邮箱（绝不随请求发送；输入过程零打扰，仅在失焦保存时校验，不合法或命中禁用名单才弹一次提示且不保存），填写合法邮箱可进入礼貌池加快查询，也可以留空。
   - **显示模式**：默认「自动」，按实际屏幕宽度自动判定手机 / 电脑布局；可手动选择「电脑」或「手机」强制布局，切换立即生效并保存。界面深浅色自动跟随系统偏好。
   - **查询设置**：
     - **每次最大查询参考文献数量**：控制单次"继续查询"处理的文献数量（1–1000）。
     - **隐藏聚焦文献连线**：开启后双向引用关系图中不显示与聚焦文献直接相连的连线（默认开启），便于观察其它引用关系。
     - **自动更新被引文献**：默认关闭，勾选后启用。距上次成功更新 ≥23h（不设上限）且距上次尝试 ≥1h 的调度点对聚焦历史文献同步一轮最新被引：按是否已拉取过 OpenAlex 被引列表分流——未并入过的（groupA）直接两源并集合并写回（不补查、不进更新历史）；已并入过的（groupB）按 DOI + openalexID 双键比对找新增（手动删除不复活，仅 W 号按 W 号判新旧，删除过的同一文献不会误判新增），新增被引建/补节点、完善数据并计入自动更新历史（供「24h 更新」弹层展示）。设置面板的「立即更新」按钮可无视开关与时间窗口立即执行一轮测试。
   - **数据源设置**：
     - **CrossRef 联系邮箱（可选）**：填写邮箱以加入 CrossRef [礼貌池（polite pool）](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)，提升请求额度。
     - **OpenAlex 联系邮箱（可选）**：填写邮箱以加入 OpenAlex [礼貌池（polite pool）](https://docs.openalex.org/how-to-use-the-api/rate-limits-and-authentication)，提升调用额度。
   - **数据管理**：保存 / 导入 / 清空数据按钮。
3. **浏览卡片组**：每张卡片为一组（含"聚焦的文献"、"引用关系图"、"选择的文献"三个区域），通过左右边条的 ◀ / ▶ 按钮切换卡片组；中央图支持滚轮缩放、拖拽平移，右下角有放大 / 缩小 / 居中按钮（时间排列下居中按钮沿横纵两个方向居中）。
4. **悬浮面板**：左侧"聚焦的文献"与右侧"选择的文献"面板展示当前文献详情；底部"Focus 历史记录"面板展示整个探索轨迹图。点击页面空白区域自动折叠面板，点击面板标题栏的图钉按钮可固定面板（固定后不自动折叠）。
5. **查看详情与引用列表**：聚焦 / 选中文献详情区展示标题、作者、期刊、出版社、发表日期、DOI、摘要、**参考文献列表**与**被引文献列表**。
6. **继续查询**：在聚焦文献详情底部点击"继续查询参考文献"或"继续查询被引文献"，批量查询该文献尚未查询的引用文献 / 被引文献。
7. **设为选中文献**：在参考文献 / 被引文献列表中点击"设为选中文献"，或在图中双击节点，可在"选择的文献"面板查看其详情与引用列表。
8. **标签**：在文献详情中可为单篇文献添加 / 删除自定义标签，便于归类和检索。
9. **复制引用**：点击"复制引用信息"按钮，将引用信息复制到剪贴板（HTML 与纯文本）。
10. **保存数据**：在"设置"弹窗的"数据管理"区域点击"保存数据"，将当前全部数据导出为 JSON 文件下载。
11. **导入数据**：在"设置"弹窗点击"导入数据"选择之前导出的 JSON 文件，即可恢复之前的全部工作状态；**导入完成自动重载页面**以确保界面与新数据一致。若文件为当前版本导出（自带数据版本 `dataUpgradeVersion`）则**跳过在线升级**，旧版本文件导入后会自动进行数据升级（在线补查补全）。
12. **清空数据**：在"设置"弹窗点击"清空数据"按钮，删除浏览器本地保存的全部数据（不可恢复，请谨慎操作）。
13. **上传补充 PDF**：在文献主条目或参考文献 / 被引文献条目中，点击"正文 PDF"或"SI PDF"按钮打开管理菜单，可多选上传多个 PDF、删除已有文件；按钮徽标显示已上传数量。文件保存在 IndexedDB，并可自动随数据恢复。
14. **查看 24h 更新速览**：点击底部信息栏最右的「24h 更新」按钮打开弹层，展示自动更新历史（每次自动更新新增的文献清单，时间倒序、保留最近 30 条）；每条文献以序号 + 标题 / 作者 / 期刊 · 出版社 · 日期 / DOI / 摘要展示，摘要默认 3 行、单击可展开全量（底部渐隐遮罩与右下角箭头徽标提示可展开）。弹层仅本地渲染、不发起任何网络请求，无底部按钮，右上角 × 关闭。
15. **手机模式操作**：窄屏（如手机浏览器）自动进入手机模式——工具栏按钮只显示图标；左右面板互斥打开（打开一侧时另一侧自动关闭），点标题栏图钉固定后不自动折叠、关闭另一侧后固定面板会自动恢复；在图中双击节点可设为选中文献，长按节点弹出操作菜单；在底部"Focus 历史记录"面板长按节点并拖动可生成浮动副本、继续拖入口袋即完成入袋；开启时间排列后年份沿纵向排列（早年份在下、晚年份在上），年份轴竖排在图左端。

## 数据说明

- **数据来源**：
  - 元数据：CrossRef REST API（`https://api.crossref.org/works/{doi}`，支持可选 mailto 礼貌池）、OpenAlex API（`https://api.openalex.org/works/{doi}`；批量场景用 `filter=doi:…` 或 `filter=openalex:<W号>…`，OpenAlex 每批 ≤100 个值 + 可选 mailto 礼貌池）。批量查询前先做 **CrossRef 列表预取**（`filter=doi:<d1>,doi:<d2>,…`，每批 ≤50 个 DOI）与 **OpenAlex 批量预热**，单篇查询命中缓存即零网络请求。
  - 被引信息：续查被引 / 自动更新时经 OpenAlex 被引列表接口（`filter=cites:<workId>`，游标分页**查全、不截断**）一次完整拉取，并与本地结果做**并集去重合并**（互补、互不兜底、互不替换）。被引次数以 OpenAlex 权威 `cited_by_count`（本地字段 `cited-by-count-from-openalex`）为口径，缺失时不做兜底。
  - 公开免费，无需强制注册；填写**合法邮箱**可进入礼貌池并解锁更高速率（CrossRef / OpenAlex 均按"有无合法邮箱"动态选择限速间隔，非法邮箱不附加 mailto、可能被源端封锁）。应用内置互斥排队式限速器控制同一数据源请求间隔，并按数据源设置 60 秒滑动窗口内的累计请求上限（CrossRef public 60 / polite 480、OpenAlex public 60 / polite 400，列表档另放宽间隔），对瞬时故障做指数退避重试（1s / 2s / 4s），429 按 `Retry-After` 头等待，避免同一来源短期窗口累计超限触发滚动 429。统一任务队列的泵在批内逐篇执行同样受同一限速器串行约束（调度并发、请求串行），批量上限：CrossRef 每批 ≤50 个 DOI（URL 长度安全上限）、OpenAlex 每批 ≤100 个值（官方 filter 单值合并上限）。
- **数据保存**：设置与 UI 状态（页面标题、口袋）保存在 `localStorage`；文献节点（v5 平铺 schema，主键为 DOI 大写）、卡片、探索历史、自动更新历史、上传的 PDF 文件自动保存在 IndexedDB（引用边与距离图不落盘，加载时派生重建），刷新页面自动恢复。亦可手动导出 / 导入 JSON 文件；导入或重载时检测到旧 v4 及更早结构数据会按空库启动，不做迁移。
- **数据隐私**：引用网络、标签与 PDF 文件仅保存在本地浏览器。对外仅可能访问 CrossRef / OpenAlex 以获取文献数据，不涉及任何第三方大模型接口。

## 兼容性

- 依赖现代浏览器 API：`fetch`、`Promise`、`Map`、`IndexedDB`、`Clipboard API`（`navigator.clipboard.write`）、`Blob`、`URL.createObjectURL`。
- 建议使用最新版 Chrome / Edge / Firefox / Safari。
- 复制引用功能依赖剪贴板 API，在非安全上下文（非 `https` / 非 `localhost`）下可能受限，建议通过本地服务器访问。
- **手机 / 窄屏支持**：窄屏自动进入手机模式，触摸手势（双击 / 长按）基于 PointerEvent 合成，兼容 Edge 手机仿真与真机浏览器；卡片组管理弹层的条目跳转（合成双击）与排序拖动（点 ☰ 手柄）同样采用 PointerEvent，触屏与鼠标行为一致。
- **DOI 输入框（触屏长按粘贴）**：上面板 DOI 输入框为普通文本输入框，已放行全局手势策略并显式排除密码框误判——手机上长按可正常唤出系统"全选 / 粘贴"菜单，不受"大声朗读 / 密码输入框"提示干扰。
- **站点图标（favicon）**：页面内嵌 SVG 品牌图标（data-URI，蓝底三节点连线，与顶部 logo 一致），浏览器标签页 / 书签直接显示，无需额外图标文件、也不请求默认 `/favicon.ico`。
